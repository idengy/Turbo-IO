## glasses-gateway（2026-10-19）

眼镜问答网关。`python3 custom/glasses-gateway/gateway.py` 监听 127.0.0.1:8650；行情问题直答（天勤数据经 futures-kb `kb quotes --json`，20 秒缓存），其余转发 Hermes 8642。
验收：`curl -N http://127.0.0.1:8650/v1/chat/completions`（带 Hermes 的 Bearer）问「自选行情」首个 data 在 1 秒内；问「你是谁」走 Hermes 原样流式。**盯盘推流（2026-10-20）**：`watch.py`（排版 + `kb stream` 子进程管理，纯 stdlib、可单测）+ gateway 两条路由，同一把 Bearer：`GET /v1/watch/names` → 65 个品种名与短名；`GET /v1/watch/resolve?q=铁矿 2701` → `{label:"铁矿石2701",display:"铁矿2701",symbol:"DCE.i2701"}`（解析交给 futures-kb `quotes.resolve_contracts`，郑商所 3 位年月；无月份 = 主连），404 = 未识别；`GET /v1/watch/stream?names=螺纹钢,铁矿石2701`（≤12，2026-10-20 r10 由 5/10 放开；品种或品种+月份，可 %XX 编码；可选 `mode=scroll`（默认，一帧发全部行，超过眼镜每屏行数的部分靠眼镜滚轮翻看，即固件字幕的历史翻看）或 `mode=rotate&page_seconds=5&page_size=7`（网关每 page_seconds 换一页，首行末尾标「1/3」，翻页本身也算变化会发帧；事件多 `page/pages` 字段。2026-10-20 实机：固件每次更新跳回最后一页，滚轮翻看只能停 3 s，所以插件默认 rotate；每页行数由插件设置传入，默认 6（max_lines 8 时短句可见 7 行、带页码的行情行只见 6 行，底部对齐挤掉首行）））→ SSE，`data: {"type":"quote","text":"10:31:05\n螺纹 3063 -0.55\n…","asof":…,"rows":[…]}`，≥1 s 一帧、永远最新快照，无变化每 ≤10 s 发 `: hb`，出错发 `{"type":"error"}` 后关；≤4 个品种首行加时钟，5 个不占位。每个品种组合一个 `futures-kb venv/bin/python -m kb stream …` 子进程，最后一个客户端走后 30 s 回收；换了合约列表时没人用的旧子进程立即关（2026-10-21，天勤免费账号并发会话有限）；exit 1 退避重启、exit 2 置错。客户端断开每秒检查一次（`_peer_gone`），不靠写失败。验收：`python3 -m unittest discover -s custom/glasses-gateway/tests -v`；`curl -N -H "Authorization: Bearer $KEY" 'http://127.0.0.1:8650/v1/watch/stream?names=螺纹钢'`（Key 从 `~/.hermes/.env` 读进变量，不打印）；断开 30 s 后 `pgrep -f "kb stream"` 为 0。
常驻用 `com.dyb.turboio-gateway.plist`(2026-10-19 已装到 `~/Library/LaunchAgents`,python 固定 Homebrew 3.11 绝对路径;改模板后 `cp` 过去再 `launchctl bootout gui/$(id -u)/com.dyb.turboio-gateway && launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.dyb.turboio-gateway.plist`)。

**盯盘暂停翻页（2026-10-21 r28）**：`GET /v1/watch/pause` 切换所有正在放的盯盘流「暂停/恢复轮播」（插件在眼镜转旋钮时调，1.5 s 内连续格算一次）；暂停时冻结当前页、首行页码后加「 停」、价格照常刷新，恢复后从该页重新计时；流重连即恢复轮播。

**手机走 5G 时「连接中」与 Tailscale（2026-10-21）**：症状 = 眼镜一直「单词本连接中 / 盯盘连接中」，网关日志无任何请求，手机 `curl` Mac 的 tailnet 地址超时。根因是 Mac 上 Clash Verge 在**全局模式**、Tailscale 的打洞/中继 UDP 被送进代理（Mac 的 DERP 落在纽伦堡），隧道闲置断开后手机无法主动重连，只有 Mac 先发包才通。**已根治**：Clash 改「规则」模式，当前配置的「编辑规则」前置 `PROCESS-NAME,io.tailscale.ipn.macsys.network-extension,DIRECT`、`DOMAIN-SUFFIX,tailscale.com|tailscale.io|ts.net,DIRECT`、`IP-CIDR,100.64.0.0/10,DIRECT,no-resolve`、`IP-CIDR6,fd7a:115c:a1e0::/48,DIRECT,no-resolve`；对照测试闲置 15 分钟后手机主动访问 0.46 s 通。**网关保活线程**（每 25 s `/sbin/ping` 手机 tailnet IP，`TS_KEEPALIVE_PEER` 默认 `100.113.176.95`）**默认暂停**：存在 `local/config/ts-keepalive-off` 即暂停（2026-10-21 起），删掉该文件即恢复，不用重启；通断变化记 `tailscale keepalive … ok/FAIL/paused`。再出「连接中」先查 Clash 是否仍是规则模式、直连规则还在，再考虑删标记开保活。不用 `tailscale ping`：LaunchAgent 里调 Tailscale.app CLI 会拉 GUI 失败且退出码仍为 0。另：网关 4xx 响应记 WARNING（含是否带 Authorization 头），Key 丢失能在日志看出。

**语音备忘自动进随记（2026-10-22 r32）**：`POST /v1/memo?memo_id=<32hex>&filename=<id>.opus&ts=<epoch ms>`，请求体 = 原始音频（≤10 MB，约 14 分钟；2026-10-21 由 2 MB 放大，网关等 suiji 600 s；Bearer 同上）→ 原样转发 suiji-bot `127.0.0.1:$SUIJI_PORT/voice`（默认 8001，超时 360 s），状态码与 JSON 原样返回：200 `{"status":"ok"|"duplicate",…}`、400/413/422 内容问题（插件不重试）、5xx/503 服务不可用（插件 1/2/5/10/30 min 退避补传）。来源是插件 `MemoForwarder`：官方 App 录完约 1 min 把录音同步成私有目录 `app_flutter/user_<uid>/audio/recordSync/<id>.opus`，插件 FileObserver 发现后大小稳定 3 s 即上传；suiji-bot 转写（ffmpeg → Apple 本机识别，失败换 whisper）、claude 起题、写当日随记 `## HH:MM 语音备忘:<标题>`，按录音 id 去重，写完飞书回执。排查转写时可 `touch local/config/memo-debug`，网关把收到的录音另存到 `local/memo-debug/<id>.opus`（默认关，用完删）。转写质量见 suiji-bot `app/ai/correct.py`（眼镜录音峰值约 -28 dB，靠 Claude 按期货品种 + Obsidian 专有词校对）。验收：`curl -X POST --data-binary @x.opus -H "Authorization: Bearer $KEY" 'http://127.0.0.1:8650/v1/memo?memo_id=<32hex>&filename=x.opus'`。

## 背单词（2026-10-20）

有道词典单词本 → 眼镜业务 19 文字面板循环显示「单词 / 音标 / 释义」，**不出声**。排版、节奏、顺序、词库全部在网关（改了即生效），插件只把盯盘的 SSE→面板壳换一个流地址（`WatchController.task`）。

**1. 拿到单词本（Bill 亲手，一次）**：Chrome 登录 https://www.youdao.com/webwordbook/wordlist （2026-10-20 实测：旧址 `dict.youdao.com/wordbook/` 是 404；这个新页面的接口是 `dict.youdao.com/wordbook/webapi/v2/word/list`，从页面 bundle 读出的）→ 看到单词卡片后按 F12 → Network 标签 → 点 **Fetch/XHR** 过滤 → 刷新页面 → 点名字为 **`list?limit=48&offset=0…`** 的请求（没有叫 `webapi/words` 的）→ 右侧 Headers → Request Headers → 找到 `Cookie:` 一行，复制冒号后面整段 → 存成 `local/config/youdao-cookie.txt`（一行，gitignored；不要贴进聊天）。必须选这条请求：它发往 dict.youdao.com，Cookie 才是接口要的那套；选 wordlist 文档那条拿到的是 www.youdao.com 的 Cookie，脚本会报 401。
备选：有道 PC 版「单词本 → 导出」得到 XML，用 `--xml 文件` 读。
手机 App 与网页条数不一致时：多半是两边登的账号不同（手机号 / 微信 / QQ 各是独立账号），或 App 没把本地词同步到云端；脚本拉的就是网页这个账号云端的词。

**2. 同步**：`python3 custom/glasses-gateway/youdao_sync.py`（或 `--xml 导出.xml`）→ 写 `local/words/wordbook.json`，原始响应落 `local/words/raw/<时间>.json`。列表条目自带英美音标（默认取美音，`--phonetic uk` 取英音）。**眼镜字体没有任何 IPA 字形（2026-10-20 实机：非英文字母的音标符号全是空白）**，网关 `words.safe_ipa` 把音标转成 ASCII 近似再上镜：sh/zh/ng/th/dh/ch/j 用英文拼法，I=ɪ、U=ʊ、@=ə、A=ɑ、O=ɔ/ɒ、V=ʌ、3=ɜ、ae=æ，重音 ' 与 ,，长音 :（表在 `IPA_FALLBACK`，改了 kickstart 网关即生效，不动 App）；个别词典里没有的词用公开的 `dict.youdao.com/jsonapi`（免登录）再补一次（`--phonetic none` 不补），结果缓存 `local/words/phonetic-cache.json`，下次只查新词。打印「写入 … N 词；单词本 {…}；本次新查音标 K 词；仍无音标 M 词」，N 应等于有道网页端的总数。Cookie 过期时报「401 用户未登录」或「接口返回 0 条」并以非 0 退出，**不覆盖**旧词库——重新复制 Cookie 再跑。网关按文件 mtime 热重载，同步后不用重启。

**3. 路由**（同一把 Bearer）：`GET /v1/words/status` → `{total, position, current_id, book_counts, updated, width, ascii_per_cell}`；`GET /v1/words/stream?seconds=6&order=seq|shuffle&probe=0|1` → SSE `data: {"type":"panel","text":"单词  /音标/\n释义…","index":n,"total":N}`，每 `seconds`（3–60）一帧，一个词释义太长拆成多帧（后续帧首行仍是单词），帧间隔 >10 s 补 `: hb`；`GET /v1/words/back`（插件在眼镜转旋钮时调）→ 切换：播放中 = 回上一个看过的词并一直停住（各帧首行末尾加 `PAUSE_MARK`「停」，放不下不加；没有上一个就停在当前词），停住中 = 继续，先重放转旋钮时正在显示的那个词再往后放（2026-10-25 Bill 定，取代 2026-10-21 r22 的「停 15 秒、连转往前退」）；`probe=1` 循环发 3 帧探针不动游标：第 1 帧音标字形探针（18 个 IPA 符号带编号 + ASCII 替换后的整词对照 + 省略号「…」可见性），第 2、3 帧宽度标尺（数字 50 / 小写 52 / 汉字 24 / 混排）；词库空发 `{"type":"error"}` 后关。游标 `local/words/state.json`：顺序模式按添加时间倒序循环、断线重连与网关重启都接着上次（2026-10-21 起：每次开始先重放上次最后送上眼镜的那个词，游标在词的第一帧送出后才提交，等待期间每秒检查客户端是否已断开，手机停止不再白吃一个没上镜的词）；随机模式一轮内不重复。

**4. 排版常量**（`words.py` 顶部）：`WIDTH=19` 汉字格/行（P0-2 实测）、`MAX_LINES=5`、`ASCII_PER_CELL=2`（一个汉字格放几个英文/音标字符，**仍未实测**；网关 `probe=1` 标尺帧还在，但手机「宽度探针」入口已在 2026-10-21 r23 随测试按钮一起移除，要测需临时加回入口）、`IPA_ASCII_ONLY=True` + `IPA_FALLBACK`（音标 ASCII 化，见第 2 步）。改任一常量后 `launchctl kickstart -k gui/$(id -u)/com.dyb.turboio-gateway` 生效，不用重装 App。

**验收**：`python3 -m unittest discover -s custom/glasses-gateway/tests -v`（test_words 29 条、test_watch 10 条）；scratch 实例 `GATEWAY_PORT=8651 TS_KEEPALIVE_PEER= WORDS_DIR=<含 wordbook.json 的目录> python3 custom/glasses-gateway/gateway.py` 下联调（盯盘用假 kb：`FUTURES_KB_ROOT` 指向含 `venv/bin/python` 与假 `kb` 包的目录，免占天勤会话）。手机端：首页「背单词 ›」→ 每帧秒数（4/6/8/10/15）、随机开关、开始/停止；眼镜语音「开始背单词 / 停止背单词」。**眼镜按键（2026-10-21 r21–r28 实机通过）**：长按旋钮 = 停止（盯盘/背单词都是，插件收到启动器 `glass_preview` aiSubtitle action=2 即释放会话）；背单词转旋钮 = 回上一个词（`/v1/words/back`）；盯盘转旋钮 = 暂停/恢复翻页（`/v1/watch/pause`）；短按在字幕面板上不报手机，无法使用。官方 App 实时字幕/同传会接管同一个固件字幕面板，盯盘/背单词随之自停，关掉官方字幕后可直接重开。待验：55 min 续期、`ASCII_PER_CELL` 实测。

**录音转写导出（2026-10-22 r36）**：`GET /v1/transcript?url=https://share.rayneo.cn/<短码>`（Bearer 同上）。官方 App「分享转写」只给链接，页面是 SPA、数据走签名接口；网关不复刻签名，用无头 Chrome（`/Applications/Google Chrome.app`，`--headless=new --dump-dom`，临时 profile，同时只跑一个，渲染不到正文时用 40 s 预算再试一次）打开分享页，`transcript.py` 按类名解析标题、日期、大纲、逐段转写，返回 `{filename, title, slices, markdown}`；非分享链接 400、无正文 422、Chrome 失败 502。插件首页「导出录音转写」调它并系统分享。单测 `tests/test_transcript.py`（合成 DOM）。
