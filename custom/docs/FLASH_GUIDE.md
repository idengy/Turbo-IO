## ⚠️ 2026-10-18 状态:刷机暂停

Bill 核对眼镜固件为 **Strix OS 1.0.5.5**,不是本指南前提的 1.0.4.12。本指南对应的 TAP1-TEST-01 是 1.0.4.12 底座,上游没有在 1.0.5.5 上验证 Android 路线,也没有 Android 版 TMIG1;1.0.5.5 新增 bt_controller 负载,往回刷等于降级,无人验证、无回退保证。**在上游发布 Android 1.0.5.5 适配之前,下面的四步不要执行。** 指南保留,等适配出来按新 Release 重新核版本和 SHA。

## 先理清「官方 App」指什么

手机上**自始至终只有一个雷鸟 AI App**。下载的 GUARD-07 APK 就是官方雷鸟 AI 1.0.5(201)的完整安装包,只是里面合并进了 Turbo IO 插件、换了签名。
- 刷机前卸载的是**现在手机里那份原厂签名的雷鸟 AI**,因为签名不同、新包装不上去。
- 装上 GUARD-07 之后,它既是官方 App(登录、配对、语音、设置、软件更新全都在),右上角多了一个 Turbo IO 插件入口。
- 后文说「回官方 App」「官方软件更新」,都是指**退出 Turbo IO 插件页、回到这同一个 App 的原厂界面**去操作,不是另一个应用。固件走的是官方自己的升级流程,插件只负责提供固件来源、预检和单次放行。

## 1. vivo X Fold 5 专项准备(刷机前做完)

从 APK 清单(minSdk 29、targetSdk 36、仅 arm64-v8a、主 Activity 锁竖屏、前台服务类型含「已连接设备」)和 OriginOS 的管控习惯推出来的。**菜单路径以手机实际为准,OriginOS 版本不同名字会变。**

1. **允许安装**:设置 → 安全与隐私 → 更多安全设置 → 「外部来源应用下载安装」或给文件管理器「安装未知应用」权限。vivo 装包时会弹「安全检测」,选继续安装。
2. **备份并卸载官方雷鸟 AI**:APK 包名相同但签名不同,装不上去会报签名冲突。先在官方 App 里导出要留的录音、稿件、配置,再卸载。卸载清沙盒,不可逆。
3. **传 APK**:426MB,用 vivo 互传、LocalSend 或数据线,别走微信(慢且可能改名)。传到手机后再核一次 SHA-256 可省略,但文件大小要是 426,640,538 字节。
4. **后台不被杀**(OriginOS 对后台最狠,OTA 过程手机要一直在前台,这几项是保险):
   - 设置 → 电池 → 后台耗电管理 → 雷鸟 AI → **允许后台高耗电**;不要开省电模式。
   - i 管家 → 应用管理 → 自启动管理 → 雷鸟 AI 允许;权限管理 → 关联启动允许。
   - 最近任务卡片下拉或长按 → **锁定**,防一键清理。
   - App 自己会请求「忽略电池优化」,弹出来就允许。
5. **权限**:蓝牙 / 附近设备、位置(选「始终允许」,官方连接要用)、通知、麦克风。按 App 的弹窗给,不要事后去系统里逐个翻。
6. **屏幕与折叠**:
   - 设置 → 显示与亮度 → 自动锁屏 → 调到最长(或开发者选项「充电时屏幕常亮」),刷机期间插着电。
   - **全程不折叠、不切内外屏**。主 Activity 是竖屏锁定,折叠切屏会触发配置变化,上游没验证过这个场景。建议用展开的内屏做完整个流程。
   - 不开「应用分身」「平行视窗」「应用克隆」。
7. **蓝牙**:系统蓝牙里只保留这一副眼镜,别同时连耳机做测试;距离一米内。
8. **眼镜**:电量 ≥ 50%,回首页,结束录音、语音、提词、导航、音乐、阅读。

## 2. 刷机四步(照抄上游,每步有停止条件)

### 第 1 步 安装 APK、连接眼镜
- 装 APK,登录,给蓝牙 / 附近设备等官方权限,连接眼镜。沿用官方连接,**不要解绑、重置、连两个宿主**。
- 打开右上角 **Turbo IO → 实验固件升级 · 默认锁定**,确认出现 **GUARD-07 · 预检有效期 2 分钟**。看不到就停。

### 第 2 步 只下载、校验,不刷
1. 插件升级页点 **「1 · 开启 15 分钟官方只下载」**,选 `TurboIO-TAP1-TEST-01.zip`。
2. 点「返回官方 App」(= 退出插件页,回这同一个 App 的原厂界面),进 **眼镜 → 设置 → 关于本机 → 软件版本**。
3. 检查更新,更新说明必须出现 **TAP1-TEST-01**。版本数字可能还是 1.0.4.12,不要因此判定失败。
4. 点官方「软件更新」让它下载、校验、解压;可能直接显示「新软件版本已准备就绪」。
5. 看到 **「开始安装」先不要点**。
- 15 分钟来源过期就重做第 2 步,不盲点升级。

### 第 3 步 预检 → 授权 → 开始安装
1. 回 Turbo IO 升级页,点 **「2 · 只读预检(不授权、不刷写)」**。
2. 等 **官方目录 15/15 校验通过**,版本、电量、空闲都是 `true`。空间可暂为 `false`。不是 15/15 就停,重新下载核 SHA,不改文件。
3. 点 **「3 · 校验目录并允许一次试刷」**,读风险说明,输入 **`TAP1-TEST-01`**,确认。
4. 等到 **授权:1 / 阶段:ARMED**,回官方弹窗,点 **「开始安装」一次**。
- 授权最长 15 分钟,退后台即撤销。
- **之后不要再点、不强退 App、不切宿主、不关蓝牙、不断电、不重启眼镜、不折叠手机。** 上传百分比只是传输进度。

### 第 4 步 必做收尾:自然重启 → 只读回查 → 释放保护
1. 眼镜自然回首页,确认菜单有 **「显示TEST」**。
2. 看菜单、仪表盘、连接和常用功能。
3. 回 **Turbo IO → 实验固件升级**,滚到底。若显示 `INSTALLING / 结果保护:待核对`,**不要再点安装**。
4. 亲眼确认更新结束、眼镜回首页、菜单正常后,点 **「已自然回首页:允许只读回查」→ 确认**。等版本=true、空闲=true 再出现。
5. 点 **「已检查显示TEST:解除结果保护」→ 确认**,只点一次。回读结果约 60 秒有效,过期重做第 4 点,不重刷。
6. 最终状态 **阶段:LOCKED、授权:0、结果保护:未开始**。LOCKED 指再次刷机默认锁定,不是功能锁。再测官方语音、录音、字幕。

**第 4、5 点不做,App 会继续拦着官方业务**(语音、录音、字幕没反应)。那是没收尾,不是要重刷。

## 3. 出问题在哪一步停

| 现象 | 处理 |
| --- | --- |
| APK 签名冲突 | 停;先导出旧 App 数据再卸载官方 App,不能覆盖 |
| 更新说明不出现 TAP1-TEST-01 | 查是否 GUARD-07、是否选对 zip、15 分钟是否过期;授权前可重做第 2 步 |
| 校验不是 15/15 | 停;重新下载并核 SHA-256,不改文件、不改白名单 |
| 电量 / 空闲 / 版本不通过 | 结束眼镜任务、恢复连接,重新只读预检,不放宽 |
| 开始被拦且 0 片 | 留状态,不连点;看第一个错误 |
| 传输 / 更新卡住、断连、黑屏 | **不重刷、不清数据、不强退、不重启**;保持供电,记时间和阶段,去上游 Issue 找维护者 |
| 回首页但「待核对」 | 按第 4 步回查释放,不是要重刷 |
| 刷完官方语音 / 录音没反应 | 先看是不是「结果保护:待核对」,按第 4 步释放 |

高级排查可导出手机 `Android/data/com.rayneo.venus.pub/files/official-ota-guard-status.txt`;发出去之前检查有没有账号、设备标识。
