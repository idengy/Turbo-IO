## 先理清「官方 App」指什么

手机上**自始至终只有一个雷鸟 AI App**。要装的 guarded 包就是官方雷鸟 AI 1.0.6(216)的完整安装包,只是里面合并进了 Turbo IO 插件、两条官方升级查询地址改指到手机本机、换成 Bill 自己的签名。
- A 段已经用同一把 keystore 装过 r2 自签包,所以这次是 **`adb install -r` 覆盖安装,登录/配对数据保留**,不用再卸官方 App。
- 装上之后,它既是官方 App(登录、配对、语音、设置、软件更新全都在),右上角多了 Turbo IO 入口。
- 后文说「回官方 App」「官方软件更新」,都是指**退出 Turbo IO 插件页、回到这同一个 App 的原厂界面**去操作。固件走的是官方自己的检测、下载、解压、Mode 2 传输流程,插件只负责提供固件来源、校验目录、单次放行。

### C 段前置(刷机前做完)

1. **换 keystore 口令**(A4 时口令曾出现在聊天里):`source custom/scripts/env.sh && keytool -storepasswd -keystore local/keys/turboio-bill.p12`,Bill 自己敲,新口令不进聊天。
2. **签名**:在自己的终端跑 `bash custom/scripts/sign_guarded.sh`(不经 Claude;apksigner 交互要口令,口令不进聊天)。脚本顺序:核对未签名包 SHA `80a485a6…` → zipalign → apksigner v3(同 alias `turboio`)→ `apksigner verify --print-certs` 证书指纹必须仍是 `4f941f05…`(否则 `adb install -r` 会因签名不同被拒)→ 第 3 条的 verify → 签名包 `local/build/TurboIO-RayNeo-1.0.6-guarded-signed.apk`,SHA 自动追加到 SUMS,手抄进第 4 节。任一步 STOP 就停。
3. **验 verify**(脚本第 5 步自动做;手动复核用同一条):`python3 android-addon/verify_apk.py <官方 APK> <签名包> --relocated classes5.dex --public-assets --guarded`。`--guarded` 是 bill 分支加的档位:只放行标记文件 `assets/turboio/official-ota-guarded.txt`(文本必须是 `ANDROID-106-OFFICIAL-OTA-GUARD-01-TMIG1`)和 `lib/arm64-v8a/libapp.so`(SHA-256 必须等于补丁后钉值 `96cc9a9f…`,即只改了两条升级查询地址)。通过标准:**退出码 0**、`unexpected_paths` 为 `[]`、`changed` 恰好是 AndroidManifest.xml、classes2.dex、libapp.so 三项、`guarded` 两项都 true。2026-10-19 对未签名 guarded 包实跑一次已满足。不加 `--guarded` 跑会把标记文件和 libapp 列为 unexpected 并非零退出,那是旧档位的正常表现,不是通过。
4. 手机侧:关 Clash、开 Tailscale 与本次无关(刷机不走网关);但**关闭官方 App 的自动更新**,眼镜电量 ≥50%,手机充电,蓝牙只连这副眼镜。

## 1. vivo X Fold 5 专项准备(刷机前做完;A 段装机时第 1、3、5 项已做过)

从 APK 清单(minSdk 29、targetSdk 36、仅 arm64-v8a、主 Activity 锁竖屏、前台服务类型含「已连接设备」)和 OriginOS 的管控习惯推出来的。**菜单路径以手机实际为准,OriginOS 版本不同名字会变。**

1. **允许安装**:设置 → 安全与隐私 → 更多安全设置 → 「外部来源应用下载安装」或给文件管理器「安装未知应用」权限。vivo 装包时会弹「安全检测」,选继续安装。
2. ~~备份并卸载官方雷鸟 AI~~ A 段已换成自签包,本次 `adb install -r` 覆盖即可;仍建议先把要留的录音分享出去。
3. **传 APK**:用数据线 `adb install -r`(A4 流程),不走微信。
4. **后台不被杀**(OriginOS 对后台最狠,OTA 过程手机要一直在前台,这几项是保险):
   - 设置 → 电池 → 后台耗电管理 → 雷鸟 AI → **允许后台高耗电**;不要开省电模式。
   - i 管家 → 应用管理 → 自启动管理 → 雷鸟 AI 允许;权限管理 → 关联启动允许。
   - 最近任务卡片下拉或长按 → **锁定**,防一键清理。
   - App 自己会请求「忽略电池优化」,弹出来就允许。
5. **权限**:蓝牙 / 附近设备、位置(选「始终允许」,官方连接要用)、通知、麦克风。按 App 的弹窗给,不要事后去系统里逐个翻。
6. **屏幕与折叠**:
   - 设置 → 显示与亮度 → 自动锁屏 → 调到最长(或开发者选项「充电时屏幕常亮」),刷机期间插着电。
   - **全程不折叠、不切内外屏**。主 Activity 是竖屏锁定,折叠切屏会触发配置变化,上游没验证过这个场景。建议用展开的内屏做完整个流程。
   - 不开「应用分身」「平行视窗」「应用克隆」。
7. **蓝牙**:系统蓝牙里只保留这一副眼镜,别同时连耳机做测试;距离一米内。
8. **眼镜**:电量 ≥ 50%,回首页,结束录音、语音、提词、导航、音乐、阅读。

## 2. 刷机四步(Android 官方链路 + TMIG1,每步有停止条件)

### 第 1 步 覆盖安装 guarded 包、确认入口
- 手机连 Mac,`adb install -r local/build/<签名 guarded 包>`;装后 `adb shell pm path com.rayneo.venus.pub` 取 base.apk 算 sha256 与签名包一致。登录、配对应保留;若提示签名冲突,停(说明 keystore 不对),不要卸载重装。
- 打开 Turbo IO → 设置/诊断 → **实验固件升级**。必须出现标题 **「官方升级 · 单次授权」**,状态第一行 **`ANDROID-106 · OFFICIAL-OTA-GUARD-01 · TMIG1`**,候选行 `TMIG1 · Strix OS 1.0.5.5 新底座迁移`,`阶段:LOCKED`、`授权:0`。
- 若只弹「本安装包没有为当前宿主版本安装 OTA 队列/文件门禁…已禁用」,说明装的是 A 段包而不是 guarded 包,停。
- 顺手复核 A 段功能没坏:语音问答(Hermes)、录音分享、官方配对。**这一步也是在验证「两个宿主类搬进 classes5.dex」没有把官方蓝牙发送弄坏**:能正常配对、语音有回应即可。

### 第 2 步 只下载、校验,不刷
1. 插件升级页点 **「1 · 开启 15 分钟官方只下载」**,选第 0 节那份 TMIG1 ZIP。状态应变成「来源已开放;请去官方更新页下载,先不要安装」;若「指定包校验失败」则 ZIP 不对,停。
2. 点「返回官方 App」,进 **眼镜 → 设置 → 关于本机 → 软件版本 → 检查更新**。
3. 更新说明必须是插件生成的那段英文 **「TMIG1 experimental firmware (Strix OS 1.0.5.5 base). AP-only; requires separate one-time authorization…」**,大小 8.4M(2026-10-20 实测官方 UI 只显示 description,不显示任务名 TMIG1 GUARDED)。版本号显示 1.0.5.5 不要当失败。出现别的版本号/说明,说明官方查询没走本机来源,停。
4. 点官方「下载/更新」让它下载、校验、解压,到「新软件版本已准备就绪 / 软件就绪」。
5. 看到 **「开始安装」先不要点**,选「稍后」。
- 15 分钟来源过期就重做第 2 步,不盲点升级。

### 第 3 步 只读预检 → 授权 → 开始安装
1. 回插件升级页,点 **「2 · 只读预检(不授权、不刷写)」**。
2. 期待状态 **「官方目录 16/16 校验通过;已提交版本/电量/空闲只读查询…」**,然后预检行 `版本=true 电量=true 空闲=true`(空间可暂为 false)。
   - 「目录/连接校验未通过」= 插件在 `files/ota/Strix_OS_1.0.5.5` 与 `app_flutter/ota/Strix_OS_1.0.5.5` 都没找到唯一且 16/16 一致的目录。**这是 B 段的推断项**:停,导出 `Android/data/com.rayneo.venus.pub/files/official-ota-guard-status.txt` 发给 Claude,查官方 1.0.6 实际解压目录名后回 B 段改常量重打包。不改文件、不改白名单。
   - 版本=false:眼镜不是 1.0.5.5 或回执没来,停。
3. 点 **「3 · 校验目录并允许一次试刷」**,读风险说明,输入 **`TMIG1`**,确认。预检有效期 2 分钟,过期回到第 1 点重做。
4. 等到 **授权:1 / 阶段:ARMED**,立即回官方弹窗,点 **「开始安装」一次**。
- 授权最长 15 分钟,退后台即撤销。
- **之后不要再点、不强退 App、不切宿主、不关蓝牙、不断电、不重启眼镜、不折叠手机。** 插件状态会走 STARTING → VERSION → MANIFEST → TRANSFER(片数增长、AP 覆盖到 7,373,064)→ INSTALLING;只看,不操作。

### 第 4 步 必做收尾:自然重启 → 只读回查 → 释放保护
1. 眼镜自然回首页,确认菜单出现 **TMIG1 的新项**(仪表盘编辑 / 应用广场(小应用)/ 导航 / 音乐 / 阅读 / 番茄等,具体以上游 TMIG1 README 为准)。
2. 看菜单、仪表盘、连接和常用功能。
3. 回插件升级页,滚到底。若显示 `INSTALLING / 结果保护:待核对`,**不要再点安装**。
4. 亲眼确认更新结束、眼镜回首页、菜单正常后,点 **「已自然回首页:允许只读回查」→ 确认**。等版本=true、空闲=true 再出现。
5. 点 **「已检查 TMIG1 新菜单:解除结果保护」→ 确认**,只点一次。回读结果约 60 秒有效,过期重做第 4 点,不重刷。
6. 最终状态 **阶段:LOCKED、授权:0、结果保护:未开始**。再测官方语音、录音、字幕,以及 Hermes 问答。

**第 4、5 点不做,App 会继续拦着官方业务**(语音、录音、字幕没反应)。那是没收尾,不是要重刷。

## 3. 出问题在哪一步停

| 现象 | 处理 |
| --- | --- |
| `adb install -r` 签名冲突 | 停;核 keystore / alias / 证书指纹 `4f941f05…`,不要卸载官方数据 |
| 插件只弹「已禁用」 | 装的不是 guarded 包;重签正确的包 |
| 配对/语音在第 1 步就不正常 | 停;可能是 classes5 搬类影响了官方蓝牙发送,装回 A 段 r2 签名包(`abe3b10f…`),把 logcat 给 Claude |
| 更新说明不出现 TMIG1 GUARDED | 查来源是否开放、是否选对 zip、15 分钟是否过期;授权前可重做第 2 步 |
| 目录校验不是 16/16 / 「目录/连接校验未通过」 | 停;可能是目录名推断错(`Strix_OS_1.0.5.5`),导出状态文件给 Claude;或重新下载核 SHA。不改文件、不改白名单 |
| 电量 / 空闲 / 版本不通过 | 结束眼镜任务、恢复连接,重新只读预检,不放宽 |
| 开始被拦且 0 片 | 留状态,不连点;看状态里「首次拦截」原因 |
| 传输 / 更新卡住、断连、黑屏 | **不重刷、不清数据、不强退、不重启**;保持供电,记时间和阶段,去上游 Issue 找维护者 |
| 回首页但「待核对」 | 按第 4 步回查释放,不是要重刷 |
| 刷完官方语音 / 录音没反应 | 先看是不是「结果保护:待核对」,按第 4 步释放 |

高级排查可导出手机 `Android/data/com.rayneo.venus.pub/files/official-ota-guard-status.txt`;发出去之前检查有没有账号、设备标识。
